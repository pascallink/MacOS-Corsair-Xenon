# docs/archive

Abgeschlossene Ausfuehrungsplaene. Sie gehoeren zu geschlossenen Issues und
beschreiben den *geplanten* Zustand zum Zeitpunkt der Planung, nicht den
aktuellen Code - als Begruendung fuer getroffene Entscheidungen lesbar, als
Anleitung nicht.

Wie ein Feature heute funktioniert, steht in der jeweiligen Doku unter
`docs/` oder im Code. Die Vorlage fuer neue Plaene liegt in
[`.github/PLAN.template.md`](../../.github/PLAN.template.md).
